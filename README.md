# Evaluación Nro. 2

Este repositorio contiene la landing page desarrollada como parte de la Evaluación Nro. 2 del curso de HTML. La página está basada en la canción *"Can't Take My Eyes Off You"* de Frankie Valli.

## Estructura del Proyecto
- **index.html**: Archivo principal de la landing page con la letra de la canción, imagen y enlace a YouTube.
- **README.md**: Información sobre el proyecto y el repositorio.

La tarea consiste en crear una landing page utilizando únicamente HTML (sin CSS ni JavaScript).
